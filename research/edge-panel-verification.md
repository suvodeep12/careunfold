## Manifest version correction

The user reported loading 0.2.6 while Edge still displayed 0.2.5. Inspection of both `.output/chrome-mv3/manifest.json` and `manifest.json` inside the 0.2.6 ZIP reproduced the mismatch: `package.json` and the archive filename were 0.2.6, while the manifest was 0.2.5. The cause was the hard-coded version in `wxt.config.ts`; this was a packaging error, not evidence of a user loading the wrong folder. The earlier claim that the ZIP was ready did not include this necessary content check.

Removing the override lets the installed WXT version derive the manifest from `package.json`. A native assertion against the old artifact failed; the new `scripts/verify-package.mjs` check runs after every `npm run zip`, including CI, and requires the built manifest version to match the package. Repackaging passes that check, all 27 tests and TypeScript. Independent ZIP-entry inspection also confirms 0.2.6 in the rebuilt archive. Installed reload remains user-operated and unverified.
