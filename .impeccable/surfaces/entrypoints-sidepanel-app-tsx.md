# Side-panel direction

Mode: Operate. User pinned revised sample star rating as the primary output and approved combining exact duplicate-text groups into one mean vote. User requested a single best direction, overriding the skill's multi-option presentation. Stack and code-first workflow confirmed. No image comps or shipping rasters.

## Direction contract
THESIS: A rating with its arithmetic exposed. The user can trace every change back to reviews; an authenticity badge would overstate the evidence.

OWN-WORLD: A white decision worksheet with ink-blue navigation, flat ruled sections and system UI lettering. The scene is a desktop user comparing clinics next to a bright browser page; dark theatrical styling would impair that comparison.

STORY: See the synthetic/sample origin, compare original and adjusted averages, toggle the exact-match adjustment, inspect grouped texts, then import a local example.

FIRST VIEWPORT: A compact name and import toolbar; explicit synthetic-data notice; clinic name and sample coverage; adjusted rating and original average together in a flat blue worksheet field; adjustment toggle immediately underneath. At side-panel width all controls remain in a single readable column.

FORM: Patient decision worksheet, grounded candidate 7, seed 29f7c9ba. The user steered the worksheet's first task to revised ratings. Challenger forms (travel wallet, airport signs, dense convention catalogue, rack timetable and data-art) were declined because they obscure numerical evidence or audience context. Kept disciplines: explicit states, immediate next action, traceable entries and consistent data alignment; no borrowed decorative motifs.
